# Zeivio
Interactive presentation software for Beginner's Paradise - FirstCommit Hackerthon

## Struktur

- `frontend/` enthält die Next.js-Anwendung.
- `backend/` ist für die spätere Backend- und Container-Konfiguration reserviert.
- Das Root-Projekt verwaltet die Frontend-Workspace-Befehle.

## Entwicklung

```powershell
npm install
npm run dev
```

Weitere Befehle:

```powershell
npm run build
npm start
```
